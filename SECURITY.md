# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Contact the DUOTECH maintainers at **tranvanthuan2005tt@gmail.com** with:
- A concise description of the vulnerability and its potential impact.
- The affected URL, file, or dependency version.
- Reproduction steps using only accounts and data you are authorized to access.
- A proof of concept that avoids accessing other users' data or disrupting service.

Please allow the maintainers reasonable time to investigate and prepare a fix before public disclosure.

## Scope

This project is a read-only dashboard for public GitHub profile and repository data. It does not intentionally access private repositories or request permissions to modify GitHub resources.

Never send passwords, access tokens, private keys, or other secrets in a report.
